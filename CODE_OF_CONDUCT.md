# Code of Conduct / Verhaltenskodex

## English

### Our Pledge

We as contributors and maintainers pledge to make participation in **ellmos-stack** a harassment-free experience for everyone, regardless of background, identity, experience level, or personal characteristics.

### Expected Behavior

- Communicate respectfully, constructively, and factually.
- Focus on reproducible technical evidence, safety boundaries, and verifiable behavior.
- Respect maintainers' time and security-first review processes.

### Unacceptable Behavior

- Harassment, personal attacks, derogatory comments, or trolling.
- Publishing private information, credentials, or personal data of others.
- Intentionally bypassing security gates or submitting unverified/deceptive claims.

### Enforcement

Project maintainers may remove or reject contributions and comments that violate this Code of Conduct. Violations can be reported via GitHub Issues or private GitHub Security Advisories at <https://github.com/ellmos-ai/ellmos-stack/security>.

## Deutsch

### Unser Versprechen

Wir als Beitragende und Maintainer verpflichten uns, die Teilnahme an **ellmos-stack** für alle Beteiligten frei von Belästigung zu gestalten — unabhängig von Hintergrund, Identität, Erfahrungsstand oder persönlichen Merkmalen.

### Erwartetes Verhalten

- Respektvolle, konstruktive und sachliche Kommunikation.
- Fokus auf reproduzierbare technische Evidenz, Sicherheitsgrenzen und überprüfbares Verhalten.
- Respekt vor den Prüf- und Sicherheitsprozessen der Maintainer.

### Inakzeptables Verhalten

- Belästigung, persönliche Angriffe, abwertende Kommentare oder Trolling.
- Veröffentlichung privater Informationen, Zugangsdaten oder personenbezogener Daten Dritter.
- Bewusstes Umgehen von Sicherheits-Gates oder Einreichen ungeprüfter/irreführender Behauptungen.

### Durchsetzung

Maintainer können Beiträge und Kommentare entfernen oder ablehnen, die gegen diesen Verhaltenskodex verstoßen. Verstöße können über GitHub Issues oder über private GitHub Security Advisories unter <https://github.com/ellmos-ai/ellmos-stack/security> gemeldet werden.
